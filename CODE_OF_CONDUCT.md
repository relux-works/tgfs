# Code of Conduct

We are committed to a welcoming, professional project community. Be respectful,
focus criticism on ideas and changes, and do not harass, discriminate against,
or expose another person's private information.

Report conduct concerns privately to the repository owners. Do not use public
issues for reports that include personal data, credentials, Telegram account
information, or security-sensitive details. Security reports follow
[SECURITY.md](SECURITY.md).

Repository maintainers may remove, edit, or reject contributions and comments
that violate this code of conduct.
