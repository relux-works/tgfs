# macOS native drive

## Description
Deliver a Finder-integrated local-first drive using File Provider, a companion TDLib host, and the shared Rust core.

## Scope
Swift application/agent, File Provider domain, App Group state, native settings, signing/notarization, and acceptance.

## Acceptance Criteria
Finder UX passes stable enumeration, hydration, pin, change, restart, upgrade, and removal gates on the support matrix.
