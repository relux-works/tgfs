# Quality, security, and release system

## Description
Build cross-platform verification, CI/supply-chain controls, performance/reliability evidence, threat models, documentation, and release governance.

## Scope
Shared and native tests, security/privacy, observability, CI/CD, SBOM/signing, support docs, and release trains.

## Acceptance Criteria
No platform release proceeds without requirement traceability, passing gates, reviewed security evidence, documented limitations, and reproducible signed artifacts.
