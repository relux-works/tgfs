# CI, build, and supply-chain pipeline

## Description
Build reproducible multi-language CI for formatting, lint, unit/conformance, native integration, secret scanning, licenses, artifacts, signing, and provenance.

## Scope
Rust, Go optional tier, Swift, Kotlin/Gradle, Windows, Linux, and documentation/board validation.

## Acceptance Criteria
Required checks protect main; artifacts map to commits; secrets remain in approved stores; failures are actionable.
