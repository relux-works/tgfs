# Local security and privacy controls

## Description
Threat-model local-first clients and implement credential, data-at-rest, redaction, cleanup, indexing, and dependency controls.

## Scope
SEC-001 through SEC-034 and SEC-050 through SEC-053 across platforms.

## Acceptance Criteria
Threat model reviewed; critical/high findings remediated; credential/logout/logging tests pass; no real secrets/content enter artifacts.
