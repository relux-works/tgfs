# Windows native drive

## Description
Deliver an Explorer-integrated local-first drive using a Rust CfAPI host and shared core.

## Scope
Sync-root lifecycle, placeholders, range hydration, pin/in-sync state, TDLib host, settings UI, signing/packaging, and acceptance.

## Acceptance Criteria
Explorer UX passes stable identity, hydration, cancellation, restart, upgrade, and removal gates on supported Windows versions.
