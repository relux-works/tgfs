# Owned Rust CfAPI abstraction

## Description
Implement or audit/fork a safe higher-level wrapper over windows-rs for sync roots, placeholders, callbacks, transfers, state, and cancellation.

## Scope
Ownership/lifetime, FILE_IDENTITY, protected handles, oplocks, error conversion, and thread model.

## Acceptance Criteria
Wrapper has focused unsafe surface, unit/integration tests, documented invariants, and no dependency on an unvetted 0.0.x API contract.
