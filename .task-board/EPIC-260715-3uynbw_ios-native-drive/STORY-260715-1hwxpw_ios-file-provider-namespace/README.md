# iOS File Provider namespace

## Description
Implement domain, item mapping, child/working-set enumeration, change anchors, and signaling over shared durable metadata.

## Scope
Thin extension, stable IDs, pages, versions, protected/unavailable capabilities, and source-offline state.

## Acceptance Criteria
Files app enumerates fixtures with app terminated; anchors recover; identity survives rename/reorder; high-water memory meets budget.
