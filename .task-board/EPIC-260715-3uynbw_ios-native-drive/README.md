# iOS and iPadOS native drive

Deliver a thin File Provider extension plus containing local-first application, with an approved cold-hydration strategy.

## Scope
Rust/UniFFI packaging, main-app TDLib, App Group state, extension namespace/content, UI, signing, memory, and acceptance.

## Acceptance Criteria
Files integration passes memory/lifecycle/identity/materialized-content gates and the cold-hydration decision is implemented and disclosed.
