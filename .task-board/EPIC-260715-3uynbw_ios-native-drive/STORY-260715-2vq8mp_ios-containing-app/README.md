# iOS containing application and engine

## Description
Host TDLib/local source and provide authorization, sync/cache status, durable queues, repair, diagnostics, and account removal.

## Scope
SwiftUI/native UI, background opportunities, network/power lifecycle, App Group coordination, and accessibility.

## Acceptance Criteria
App state machine survives suspension/termination; required user actions are accessible; no unsupported background guarantee is implied.
