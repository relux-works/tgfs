# Confirm protected and secret content policy

## Description
Define behavior for protected content, view-once/self-destruct media, secret chats, unavailable locators, and inaccessible history.

## Scope
Compliance behavior, namespace placeholders, diagnostics, and product wording.

## Acceptance Criteria
Policy complies with Telegram restrictions, avoids overpromising all files, and defines explicit user-visible unavailable states.
