# Local TDLib source

## Description
Implement per-device Telegram authorization and normalized DriveSource behavior through TDLib tdjson.

## Scope
TDLib packaging, auth/session lifecycle, namespace/history/updates, file download, backfill, and diagnostics.

## Acceptance Criteria
Source passes shared conformance and large-account/restart tests, respects Telegram restrictions, and supports desktop/Android local-first providers.
