# Android Rust and TDLib runtime integration

## Description
Package Rust/UniFFI and TDLib for selected ABIs and coordinate provider/application process lifecycle.

## Scope
Gradle modules, JNI libraries, initialization, cancellation, process death, secure storage, and diagnostics.

## Acceptance Criteria
Reference app builds per ABI, cold/recreated provider initializes safely, and memory/startup measurements meet provisional budgets.
